# Alphonsa Thomas — Academic Portfolio

A responsive, single-page personal portfolio built with plain HTML, CSS and JavaScript.

## Project structure

```text
alphonsa-thomas-portfolio/
├── index.html
├── style.css
├── script.js
├── assets/
│   └── profile.jpg
└── README.md
```

## Run locally

1. Extract the project folder.
2. Open `index.html` in a web browser.

No build tools or dependencies are required. Google Fonts are loaded online; system fallback fonts are included.

## Customization

- Update text and links in `index.html`.
- Change colours, spacing and layout in `style.css` using the CSS variables at the top.
- Update navigation behaviour or other interactions in `script.js`.
- Replace `assets/profile.jpg` to use a different portrait.

## Privacy

The public-facing page includes the institutional email address from the supplied biodata. Personal email, postal address, gender, and religion/caste details have been left out because they are not needed for a professional portfolio.
